# Framework adapters (M13)

Tier-1 adapters: one module per framework under `python/strata/integrations/`,
each filling the framework's own JSON hook with strata's entry points and
nothing else (docs/roadmap/SKILL.md, M13; public surface: docs/context/api.md,
Framework adapters). The adapters hold no logic beyond mapping the hook's
arguments onto `strata.dumps`, `strata.dumps_with_default` and `strata.loads`.
Tests: `tests/integrations/test_{flask,django,aiohttp,falcon,structlog}.py`
and `test_adapter_imports.py`, run by `make test-integrations` and the
`integrations` CI job, never by `make test`, `make gate` or the PGO profile.

## Hook contracts, read from the installed source

Verified 2026-09-28 against Flask 3.1.3 (Werkzeug 3.1.9, Jinja2 3.1.6),
Django 6.1.1, aiohttp 3.14.3, Falcon 4.3.1 and structlog 26.1.0.

| Framework | Hook                                                                                  | What calls it, with what                                                                                                                                                                                                                                                                                                                                       | Adapter                                                                                                                                                                                                                                                                                                                                                    |
| --------- | ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Flask     | `app.json` / `json_provider_class` (`flask.json.provider`)                            | `DefaultJSONProvider.response` calls `self.dumps(obj, separators=…)`, or `indent=2` in debug, and appends `"\n"`; the session serializer (`flask.json.tag`) calls `dumps(…, separators=(",", ":"))` and, from 3.0.1, `loads(value)`; Jinja's `tojson` calls `dumps(obj, sort_keys=True)`; `Request.get_json` calls `loads(bytes)` and maps `ValueError` to 400 | `StrataJSONProvider(DefaultJSONProvider)`: `dumps(obj, *, default, separators, indent, sort_keys)` → `dumps_with_default(obj, default)` when `default` is given, else with `self.default`; the last three ignored and any other keyword a `TypeError`; `loads(s)` → `strata.loads(s)`; `response` inherited                                                |
| Django    | `JsonResponse(encoder=)`                                                              | `json.dumps(data, cls=encoder, **json_dumps_params)`, which constructs the encoder with every `JSONEncoder` option on every call and calls `encode`; `json.dump` calls `iterencode`                                                                                                                                                                            | `StrataJSONEncoder(DjangoJSONEncoder)`: `encode(o)` → `dumps_with_default(o, self.default)` after refusing, with `TypeError`, any of `skipkeys`, `allow_nan`, `sort_keys`, `indent`, `separators` off its default (`ensure_ascii` and `check_circular` ignored; `separators=(",", ":")`, strata's own form, accepted); `iterencode` yields that one string |
| aiohttp   | `web.json_response(dumps=)`, `ClientSession(json_serialize=)`, `request.json(loads=)` | `dumps(data)` must return `str` (`JSONEncoder = Callable[[Any], str]`); `loads(text)` gets the decoded body; a `ValueError` is not mapped (500)                                                                                                                                                                                                                | `dumps = strata.dumps`, `loads = strata.loads`, `json_response(*a, **kw)` → `web.json_response(*a, dumps=dumps, **kw)`                                                                                                                                                                                                                                     |
| Falcon    | `falcon.media.JSONHandler(dumps=, loads=)`                                            | probes `dumps` once: a `bytes` result is written as it is; `loads(data.decode())`, with `ValueError` mapped to `MediaMalformedError` (400); the optimized media path is kept only when the handler is not subclassed                                                                                                                                           | `json_handler()` → a plain `JSONHandler(dumps=partial(strata.dumps, return_type="bytes"), loads=strata.loads)`                                                                                                                                                                                                                                             |

## Semantic differences

Against each framework's default serializer as shipped: "default → strata",
and "same" where the framework's default already behaves as strata does; "—"
where the framework has no such path. Every cell's strata side is asserted in
the framework's test module.

The two nesting rows read stdlib `json` on CPython 3.12+, whose C guard is the
C stack; on 3.10 and 3.11 it is the interpreter's recursion limit, and stdlib
fails both depths too, with `RecursionError` (500 where the framework does not
propagate it). Strata's limits are version-independent: 1024 containers when
parsing, `sys.getrecursionlimit()` when serializing (docs/context/api.md). The
`default=None` row is `dumps_with_default`'s refusal, where stdlib's
`default=None` means "no hook" and fails only on an unsupported value.

**Chain bound 1, and the workaround.** `dumps_with_default` does not call the
hook on its own return value; stdlib does, without limit. A `default` that
returns a `Decimal` — Django: `return o.amount` in a `StrataJSONEncoder`
subclass; Flask: the same in a provider's `default`; structlog: an
`__structlog__` returning `self.amount` — writes `"1.50"` under Django's and
Flask's defaults (`"Decimal('1.50')"` under structlog's, via `repr`) and is a
`TypeError` here. The loop belongs inside the callable, one line each:
`return super().default(o.amount)` (Django),
`return DefaultJSONProvider.default(o.amount)` (Flask),
`return str(self.amount)` (structlog). Each is a test in the framework's
module.

## Version floors

The floor is the oldest release on which the adapter's suite passes on every
supported CPython (3.10–3.14), found by bisection on 3.14 (the binding end:
newer interpreters remove what old releases import) and confirmed on 3.10
(2026-09-28, CPython 3.10.20: the floors and the newest releases 3.10 allows,
Django 5.2.17 among them, both pass), which the CI `floors` leg repeats:

| Framework | Floor                  | Why not older                                                                                                                                                                                                                             |
| --------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Flask     | 3.0.1 (Werkzeug 3.0.0) | 3.0.0's session serializer calls `loads(value, object_hook=…)`, which the adapter refuses (ignoring it would leave tagged session values untagged); 2.2–2.3 need a Werkzeug that fails on 3.14 (`ast.Str`) or a test client that does not |
| Django    | 4.1                    | 4.0 imports `cgi` and 3.2 `distutils`, both gone in 3.13/3.12                                                                                                                                                                             |
| aiohttp   | 3.9.0                  | 3.8.6 does not build on 3.14                                                                                                                                                                                                              |
| Falcon    | 4.0.0                  | 3.x does not build on 3.14 (`cgi`)                                                                                                                                                                                                        |
| structlog | 20.2.0                 | 20.1.0 refuses a `bytes` render (`return_type="bytes"`)                                                                                                                                                                                   |

`pyproject.toml`'s `integrations` extra carries these as `>=` floors; the CI
`floors` leg installs them exactly on Python 3.10, the `latest` leg the newest
releases on 3.14.
